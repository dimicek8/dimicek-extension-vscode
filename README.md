# Dimicek

Git & GitHub workflow for VS Code inspired by IntelliJ IDEA.

> **Status:** early development — not yet published on the Marketplace.

## Planned features

- **Commit window** — changes with checkboxes, unversioned files, commit message, amend, commit and push
- **Git Log** — commit graph, filters, commit details and changed files
- **Branches popup** — checkout, create, merge, rebase, compare from the status bar
- **Push dialog** and **Update Project** (fetch + merge/rebase)
- File history, blame, stash, conflict resolution
- GitHub integration — clone, pull requests

## Development

```bash
npm install
npm run watch   # rebuild on change
```

Press **F5** in VS Code to launch an Extension Development Host with the extension loaded.
